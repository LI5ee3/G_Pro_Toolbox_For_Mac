# R6c：权限入口与本机收尾验证

2026-10-22，macOS 27.0.1、Mac mini M4。最终开发构建为 **20261022.8**，已在原路径更新并保持运行。本批只调整网络权限入口的导航与说明、打开失败处理及两个回归测试；ADB 实现、协议、预设、其他 UI 布局与系统服务实现没有改变。正式签名、公证和公开发布按用户要求暂缓。

## 网络权限入口的实际边界

本机系统接受 `Privacy_LocalNetwork` 等候选 URL，但最终停在隐私首页，不能把 `NSWorkspace.open == true` 当作子页面定位成功。无锚点的现代隐私扩展 URL 又会恢复上次子页面，可能回到辅助功能。

最终使用已经实际验证的 `x-apple.systempreferences:com.apple.preference.security?Privacy` 返回“隐私与安全”首页。按钮改为“打开隐私设置”，旁边明确提示“打开后选择‘本地网络’，检查本应用开关”，并提供完整路径帮助。**仍需用户再点一次“本地网络”，没有宣称一步直达。** 不依赖私有设置 API、自动点击系统界面或额外授权。

系统拒绝打开 URL 时，日志给出手动路径；接受时只说“已请求打开”，不推断网络授权状态。原有“网络或设备故障也可能导致连接失败”的判断边界保留。Preview 只记录内存意图，不调用真实系统设置。

已从最终安装 App 点击入口，确认从辅助功能子页返回隐私首页；再按提示进入“本地网络”，核对 ToolBox 开关开启，没有切换本地网络权限。系统因不同 ad-hoc 身份保留的同名历史记录没有被批量清理。
