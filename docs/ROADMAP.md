## 1. 范围与执行原则

### 1.1 当前范围

- 仅维护 Apple Silicon、macOS 27+ 的 Mac 应用；使用 SwiftUI、AppKit、Observation、CoreAudio、ServiceManagement 等现有 Apple SDK 和项目实现。
- 优先复用原作者已有实现及修复，只做必要适配、定制和具体缺陷修复。保留正常工作的定制及有效修复，不因统一架构、命名、文件大小或语言模式调整无关模块。
- S3-01 已采用“控制优先的原生工作区”，S3-01 至 S3-08 已 review 合并。现行视觉及交互规范见 [DESIGN](../DESIGN.md)，不要求重新设计或重做既有证据。
- 保留手动 USB/TCP 选择、主动切换、所选传输恢复、显式断开抑制及现有会话安全机制。跨 USB/TCP 的 Auto 自动切换为 **DEFERRED**，除非用户明确重新启动；不为未来 Auto 新增稳定窗口、冷却、退避、状态机或专属测试。
- 不新增设备协议，不重写 adb USB/RSA 协议；显示器 Android 侧所需 JAR/APK 继续沿用现有实现。
- Developer ID、公证、App Store、公开二进制发布、Windows、Intel Mac 和低版本 macOS 不在当前范围。
- 本次仅整理文档。**G1 PASS，历史 M2/G2 NOT_PASSED，G3 REVIEW_PENDING，Auto DEFERRED**；本次不启动阶段四、构建候选或操作设备。

### 1.2 修改与验证

1. 修改须对应明确需求、已观察到的异常或代码可直接定位的实际缺陷。先查当前范围内的上游和已有接口，复用会话、取消、队列及状态发布机制，不为假设场景增加框架、抽象层、状态机、重试、去重或配置。
2. Review 聚焦实际正确性和本次影响；发现范围外问题可简短记录，不自动转为任务，不扩大为全库审计或大规模回滚。
3. 沿用已有测试和默认 CI，不设新增测试数量目标。只有关键行为无法由现有检查覆盖时才补最小、直接的验证；文档及简单可逆改动不增加功能测试，不为测试建立通用设施。
4. 未改变的上游功能和已有充分证据沿用原结论。除定位具体失败所需，本机不重复默认 CI 已覆盖的完整回归和全部构建；不因新提交而重新验收整套功能。
5. 按用户最新确定的范围缩减不再适用的验收要求。旧 M2/G2、阶段锁定、固定次数拔插/切换/睡眠、长时间观察或整组参数写入均不自动成为后续任务前置条件；已有证据充分后停止扩大检查。
6. 提交、推送、合并及真机操作按已获授权的范围推进，不重复请求已有授权；未启动的任务不因路线图列出便自动执行。

### 1.3 工作区与设备边界

- 保留无关工作区内容、既有工作树和历史标签；提交只包含当前任务所需改动，不重写历史或移动旧标签。
- 构建或候选交付确有需要时使用独立新输出目录，复用现有 development 流程。DMG/ZIP、安装覆盖、权限重绑、偏好清理和 adb 密钥重置不由普通文档或验证工作连带触发。
- 真机操作仅在当前任务确有需要且已获授权的范围内进行。高风险写入先明确具体目标、原值和恢复方案；测试清单不构成写入授权，已有授权不重复询问。
- 生产连接可能触发自动任务、记忆恢复和 ensureJars 写入；需要只读检查时先查明实际副作用，复用适用的只读探针，不凭方法名判断。

## 3. 保留的 ADB 实现约束

- 发现与授权复用锁定官方 adb 和现有有界执行器；设备命令明确指定端点，不猜列表第一台，不把 USB serial 当成 TCP 地址，不替用户同意授权或删除密钥。
- 保留 `saved_ip`、快捷键/记忆键、`picture_presets_v1` 的兼容和现有身份归属规则。设备身份独立于传输地址；未知、冲突或未经确认的身份不自动迁移数据或向另一设备恢复基线。
- 同时只允许一个活动命令会话。复用既有不可变会话快照、代次、父子取消、FIFO/事务锁和 operation ID；切换、断开、stop、睡眠后的旧结果不刷新新 UI 或缓存。
- 保留手动 USB/TCP 的同传输恢复与显式断开抑制，不自动跨传输回退。健康会话不因另一传输故障被无故重启。
- 写入、toggle、预设和任务在中断后不盲目重放；保留不完整状态及现有回读、账务处理。不宣称远端命令可撤回或具备未经证明的 exactly-once 保证。
- 不因补齐历史设计而另造监听器、会话层或恢复系统；只在当前范围内存在实际缺陷时局部修复。Auto 未来方案仍为 DEFERRED，不预埋实现。
