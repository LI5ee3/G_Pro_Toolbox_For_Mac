# S2-03 最小计划：手动 USB/TCP 与安全模拟

起点 `2251cda`；S2-02 全量 327 Swift 与源边界通过后开始。进度以 [ROADMAP](../ROADMAP.md) 为准。

1. 保留 ConnectionModel 为唯一连接状态所有者；在原状态上增加待授权、离线、失败，手动模式、明确候选与活动端点分开。发现快照/代次独立，不替换连接状态、不自动选第一项。
2. 复用 S2-02 的 fresh USB 验证和原 TCP 接入路径；新 TCP 输入校验复用发现解析的主机规则，端口独立，不改旧低层 TCP factory 字节语义。手动选择/重试推进 intent，晚到结果不激活。USB 验证成功后只发布通道 ready，不运行旧 connect 的 helper/记忆/任务初始化；身份未完成时禁止预设与自动副作用。
3. USB 模式（包括未授权/失败且 active endpoint 为空）禁止旧监控回落 saved_ip。逻辑断开、模式变更与扫描不会解除手动断开抑制；只有显式接入开始新 intent。
4. UI 仅复用现有 SectionCard、Picker、按钮和文字；显示模式、实际活动端点、候选状态及身份限制。未知传输可明确请求验证所选 USB 候选，但必须通过 fresh 列表与 get-devpath；重复/不支持不可接入。不开放 Auto，不进行阶段三视觉重设计。
5. Preview 增 USB ready、未授权、离线、多候选、USB/TCP 同时在线；仅内存数据、假执行器与虚拟时钟，保持宿主零偏好写入和四层隔离。

验证：新增协调器选择/取消/独立发现/无目标和身份受限副作用测试，保留既有测试；完整 Swift、架构与 Preview 检查，独立 Preview Debug 构建并实际交互、窗口变化与退出重启，记录子进程/INET/偏好采样。真实设备 HW_NOT_TESTED。

本项不创建身份登记、不迁移旧配置、不开放恢复/Auto。S2-04 将用身份能力替换临时 USB 限制；S2-06 才开放同端点生命周期恢复。回滚以新提交撤销，原 App/配置/密钥不变，无安装/打包或真机操作。

结果：24 新增 / 351 Swift 全量 PASS；架构、Preview 源/二进制/资源、独立 Debug 构建及实际交互通过。336 次运行采样无子进程/INET/用户偏好变化，现用 App 与密钥保持；详见 [S2 报告](S2.md)。LOCAL_PASS，整阶段 CI 待复验。
